# 교직원 연수 이수증 수합 웹 애플리케이션 (React + TypeScript)

교직원이 별도로 제출한 연수 이수증의 **제출 여부를 간편하게 등록하고 실시간으로 관리 및 집계**할 수 있는 웹 애플리케이션입니다.

## 주요 기능

### 📮 교직원 화면 (Staff Mode)
- **간편한 터치/클릭 워크플로우**:
  1. 시작 화면에서 '이수증을 제출하셨나요?' 안내와 함께 '제출 여부 등록하기' 클릭
  2. 교직원 명단에서 본인 이름 선택 (60초 무조작 시 자동 초기화)
  3. 이수증을 제출한 연수 선택 (기제출 항목은 완료 표시 및 비활성화, 마감일 및 지남 알림)
  4. 제출 전 확인 창 안내 후 등록 완료
  5. 등록 완료 화면 (5초 카운트다운 후 홈으로 복귀)
- **관리자 진입**: 우측 상단 실시간 시계를 클릭하여 숫자 키패드로 관리자 비밀번호를 입력하면 관리자 화면으로 진입할 수 있습니다.

### 📋 관리자 화면 (Admin Dashboard)
- **📊 제출 현황**:
  - 각 연수별 도넛 차트 진행률, 제출 인원수, 마감 현황
  - 연수별 미제출 교직원 명단 확인 및 원클릭 클립보드 복사
  - 실시간 교직원 × 연수 현황 매트릭스 표 (교직원 등록 / 담당자 확인 / 미제출 표시)
  - 표의 각 셀을 클릭하여 즉시 제출 확인 / 취소 처리 토글
  - 미제출 교직원만 필터링 기능
  - 엑셀(CSV) 다운로드 (UTF-8 BOM 지원)
- **📝 연수 관리**:
  - 신규 연수 추가 (연수명, 마감일)
  - 등록된 연수 목록 조회 및 삭제
- **👥 교직원 명단**:
  - 한 줄에 한 명씩 `번호 이름` 형식으로 편리하게 등록/수정
  - 중복 검사 및 명단 저장
- **⚙️ 설정 · 연동**:
  - Google 스프레드시트 Apps Script 웹 앱 URL 및 비밀번호 연동
  - Apps Script 배포 단계별 안내 및 원클릭 스크립트 코드 복사 기능
  - 관리자 비밀번호 변경 기능
  - 브라우저 로컬 데모 데이터 초기화 기능

## 기술 스택
- **프런트엔드**: React 19, TypeScript, Vite, Tailwind CSS
- **저장소/백엔드**:
  - **기본 데모 모드**: 브라우저 `localStorage` 기반 즉시 체험
  - **구글 스프레드시트 연동**: Google Apps Script 웹 앱 API 연동 지원
